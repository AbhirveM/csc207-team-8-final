## Contribution workflow

We use a **branch → pull request → review** workflow. Do not commit directly to `main`.

1. Create a feature branch off `main`:
   ```bash
   git checkout main && git pull
   git checkout -b feature/short-description
   ```
2. Commit your work with clear, descriptive messages.
3. Push and open a Pull Request against `main`.
4. Have at least one teammate review before merging.
5. Keep `main` always in a working, buildable state.
